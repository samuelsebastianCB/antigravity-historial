# Respaldo Completo Antigravity + Proyectos (Sin USB)

En tu otra PC, abre una terminal (PowerShell) y ejecuta este único bloque de comandos para restaurar **todo el historial de Antigravity** y clonar tus proyectos sin usar USB:

```powershell
git clone https://github.com/samuelsebastianCB/antigravity-historial.git
cd antigravity-historial
.\restaurar_en_otra_pc.ps1
```
